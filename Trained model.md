# Trained / Saved Model

## What this covers

The trained model weights submitted for the project. This is the convolutional GAN, using transposed convolutions in the Generator and strided convolutions in the Discriminator, since this is the model that was actually trained to produce the submitted results, plots, and screenshots.

Note: the project report and presentation explain a simpler fully-connected (MLP) architecture for clarity. The saved model below does not match that explanation layer for layer, since it is the convolutional implementation, not the fully-connected one. Keep this in mind if asked to load the model and walk through its architecture directly.

## Files

| File | Description | Size |
|---|---|---|
| `Trained model/model networks/generator.pth` | Generator weights after 50 epochs of training | 7,852,252 bytes (~7.9 MB) |
| `Trained model/model networks/discriminator.pth` | Discriminator weights after 50 epochs of training | 2,646,836 bytes (~2.6 MB) |

Both files are PyTorch state dictionaries saved with `torch.save(model.state_dict(), path)` at the end of training. They contain only the learned weights and biases, not the optimizer state, so they are meant to be loaded into a freshly constructed model for inference or further inspection, not to resume training from this exact point.

## Architecture summary

| Property | Value |
|---|---|
| Generator parameters | 1,961,286 |
| Discriminator parameters | 660,229 |
| Latent dimension | 100 |
| Generator | Linear projection, reshaped to (256, 7, 7), then two ConvTranspose2d + BatchNorm + ReLU blocks, then a final Conv2d + Tanh |
| Discriminator | Three Conv2d + BatchNorm + LeakyReLU blocks, flattened, then a Linear layer + Sigmoid |

## Produced by

Trained by running `Source code.py` end to end:

| Setting | Value |

The full set of sample images and plots generated across training is in `Trained model/Results plots and screenshots/`, and these are the images that also appear in the report and presentation.

## Loading the model

```python
import torch
from Source_code import Generator, Discriminator

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

G = Generator(latent_dim=100, features_g=64, channels=1).to(device)
G.load_state_dict(torch.load("Trained model/model networks/generator.pth", map_location=device))
G.eval()

D = Discriminator(channels=1, features_d=64).to(device)
D.load_state_dict(torch.load("Trained model/model networks/discriminator.pth", map_location=device))
D.eval()
```

Once loaded, new digit images can be generated by passing random noise through the Generator:

```python
with torch.no_grad():
    noise = torch.randn(16, 100, device=device)
    samples = G(noise)
```

Note: `Source code.py` would need to be renamed to a valid Python module name (for example `source_code.py`) for the `import` line above to work as written, since filenames with spaces cannot be imported directly.
